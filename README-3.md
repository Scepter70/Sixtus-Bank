# Sixtus Bank

A multi-currency banking web application built with **Python** and **Streamlit**, featuring a custom "Vault & Ledger" design system — an animated navy-and-gold interface with a full marketing landing page.

## Features

- Animated landing page with hero section, trust stats, and feature highlights
- User registration and secure login
- Admin panel
- Multi-currency wallets (USD, EUR, GBP, CAD, AUD, CHF, JPY, NGN)
- Deposit and withdraw
- Currency exchange between wallets
- Full transaction history and audit trail
- Password hashing (PBKDF2) for security
- SQLite database
- Custom glassmorphic UI with gold-accented animations

## Technologies Used

- Python
- Streamlit
- SQLite

## How to Run Locally

```
pip install streamlit
streamlit run app.py
```

## Deploying on Streamlit Community Cloud

1. Push `app.py` to a GitHub repository.
2. Go to [share.streamlit.io/deploy](https://share.streamlit.io/deploy).
3. Set **Repository** to your repo, **Branch** to `main`, and **Main file path** to `app.py`.
4. Click **Deploy**.
